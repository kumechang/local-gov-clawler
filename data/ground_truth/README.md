## 記入のしかた(`sports_hub_nara.csv` の `hub_url` 列)
1. `site_url` を開く。サイト内検索は使わず、普通の利用者のようにメニューをたどる
   (「スポーツ」「体育施設」「施設案内」「公共施設」など)。
2. **体育館・グラウンド・運動公園などの一覧が載っている、トップに最も近いページ**のURLを記入する。
   - 個別施設の1ページ(例: 「○○体育館」)ではなく、複数の施設が並ぶ一覧ページを選ぶ
   - 一覧が無く、カテゴリページに施設へのリンクが並んでいる場合は、そのカテゴリページ
   - 予約システムのページは選ばない(対象外)
3. そのような一覧ページが**サイトに無い**場合は、`hub_url` を空のままにして `notes` に「なし」と書く
   (その行は評価の母数に含まれない)。10件に満たなくてもよい。
4. 迷ったら `notes` にメモ(例: 「候補が2つあり、こちらは施設別の表」)。

## 評価
`localgov-crawler evaluate --route <route> --truth data/ground_truth/sports_hub_nara.csv`

- 「到達」の定義: 正解URLが、そのクローラー結果のハブ候補上位5件(`genre_entrypoints[].candidates`)に含まれること
  (末尾スラッシュとフラグメントの違いは無視)
- 「確定して正解」: `hub_selected` したURLが正解と一致すること(一致しない確定は誤採用)。プログラムだけで使える水準はこちらで測る
