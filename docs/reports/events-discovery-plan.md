# イベント専用の探索の計画(evd1_*)

ユーザー判断(2026-11-04): 「イベント専用の探索を足す」。あわせて「北海道は見逃しでOK」(ワード調査で北海道のグラウンドゴルフが1%だったのは、パークゴルフが主流のためでなく、見逃し)。

## なぜ足すか
既存のイベントのデータは、ワード調査(施設を探すための調査)のついでに見つかったページだけ。ワード調査では、イベントのページは優先度が最後で、1自治体80ページまで。結果、イベントの入口を見つけた自治体は1,618あるが、イベントのページを取れた数の中央値は11ページ、イベントのページが0の自治体が208。グラウンドゴルフのイベントのあるページがある自治体は208(全国の約12%)にとどまる。

## 方法(段階)
1. **探索(今回、`evd1_<都道府県>` ×47)**: 既存のワード調査と同じ仕組み(`survey`)に `--event-focus` を足した。
   - 入口: ナビの『イベント・行事・カレンダー・催し・大会・スケジュール・新着・お知らせ・ニュース・広報・スポーツ』と、従来のスポーツの入口。
   - イベントのページを優先してたどる(従来は最後)。一覧のページ送り(次へ・次の月・前月・番号)もたどる。
   - 1自治体300ページまで、入口から3階層(従来は200ページ・2階層)。取得ルールは同じ(robots順守、1ホスト1リクエスト/秒以下、予約・ログイン・CAPTCHA・WAFには入らない)。
2. **取り出し(次の段階、`config/survey_sets/grandgolf_events.json` のrouteを対象に `events`)**: 探索で見つかったイベントのページから、第2版と同じ取り出しで名称・開催日・会場などを取る。既存の第2版の結果と合わせ、同じイベント(同じ自治体・名称・開催日)は1行にする。

## 見積もり
- 対象: 全国の調査済みの自治体(約1,700。政令市の区は除く)。
- リクエスト数: 1自治体あたり、現在のイベントのページ(平均19ページ)の数倍と見て、100〜200ページ程度 → 全体で十数万〜30万リクエスト。
- 時間: 1ホスト1リクエスト/秒以下、都道府県ごとに並列。最も多い北海道(188自治体)で数時間、全体は数時間で終わる見込み(GitHub Actions、公開リポジトリのため時間数は気にしない)。

## 事前基準(探索)
| # | 項目 | 基準 |
|---|---|---|
| 1 | 調べられた自治体 | 従来のワード調査(surveyed 約2,150件の実行を含む)と同程度(未取得・入口なしは別に記録) |
| 2 | 取得ルール違反 | 0 |

## 北海道について
ユーザーは『見逃し』と判断。手元で旭川市・岩見沢市・恵庭市を確認したところ、市のサイトのスポーツ関連ページは多くがパークゴルフの記述で、取得済みの施設一覧のページにはグラウンドゴルフの語が無かった。旭川市はPDF(『市内パークゴルフ場』の資料)に『グラウンドゴルフ場』の記載があるとの検索結果があり、PDFの中身は今の調査では読んでいない。北海道の見逃しの主な原因は **PDFの中の記載** の可能性が高い。今回のイベント専用の探索(北海道を含む)で、まずイベントの見逃しを減らし、施設の見逃し(PDFを読む)は別の段階として設計する。
