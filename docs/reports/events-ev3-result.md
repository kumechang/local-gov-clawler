- 令和7年度以降(期間内)382行・207自治体。グラウンドゴルフ専用(期間外を除く)117行・73自治体。
- 合算の開催日 59.7%・会場 40.8%。

## 低かった理由
- ev3 は『その他』(302行)が多い。お知らせ・活動日記・結果で、会場や開催日がページに無い・文中にだけある。
- カレンダー(110行)はJavaScriptで描画するもの(福山市・さつま町など)が多く、日付が取れない。
- 題名がサイト名のページがあり、イベント名に自治体名が入る(吉川市)。
