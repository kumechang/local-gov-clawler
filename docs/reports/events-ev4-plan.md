## 変更
1. **イベント名**: h1が自治体名・サイト名(『○○市公式ホームページ』)・『イベント』などのとき、本文の見出し(h2・h3)からイベントらしいもの(ワード・大会・教室・募集など)を選ぶ。
2. **項目の値**: 次の項目の番号(『3.参加人数』)と注記(※)から後ろを落とす。
3. **月間カレンダー**: 『N日』『土曜日』の見出しの下にイベントが並ぶ型を読む。日付=直前の見出しと『2026年11月』(『2026年』『(令和8年)』『11月』が別の行でもよい)、期間の『日』・『時間』・『場所』の項目、同じイベントは1つ。『場所』の値(会場名にグラウンドゴルフ場)は、イベントにしない。実ページ: 福山市は2件(11月15日、11月21日)、さつま町は11月28日を取れる(ev3は日付なし)。
4. **対象ページ**: 探索(evd1)で見つかったページと、ワード調査のついでに見つかったページを合わせる(841ページ、313自治体、44都道府県)。同じURLは1つ。ev2・ev3の結果を置き換える(合算の手間をなくす)。
