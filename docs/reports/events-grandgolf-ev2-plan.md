# イベント調査 第2版(ev2_*)の計画

第1版(D-138)の原因調査から。route=`ev2_<都道府県>`(44)、対象・取得ルールは第1版と同じ。実行前に決める。

## 変更
1. 括弧つきの項目名(【開催日】【場所】【参加費】【申込期間】【主催】)を読む。
2. 表: 見出し行の空白を除いて列の役割(日付・会場・名称・申込締切など)を判定する。見出し行が先頭の3行のどれでもよい。月と日が別の列の表、結合された行で先頭の列(月・日付)が省かれる表(前の行の値を使う)に対応。
3. カレンダー・予定表: 日付が『31日』『土曜日』の別の行にあるとき、直前の『2026年10月』と日の行から日付を作る。

実ページ(取得済みのもの)で確認: 玉村町・中之条町・橋本市・高浜町・東松島市のイベントの日付・会場・申込締切が取れる(第1版は取れなかった)。
