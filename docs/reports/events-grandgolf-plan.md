# グラウンドゴルフのイベント調査の計画(第1版)

ユーザー依頼(2026-11-04): 「各市区町村で開催しているグランドゴルフのイベントを調査したい」。

## ユーザーの決定(D-137)
- **範囲**: 広く全部(グラウンドゴルフ専用の大会・教室・体験会、複数競技の大会の種目、カレンダー・予定表、結果・報告)。区別できるよう `event_kind` に種類を入れる。
- **期間**: 令和7年度(2025年4月)以降。期間外・日付不明も消さず、`period`(期間内/期間外/日付不明)に入れる。
- **項目**: 名称・開催日・会場、主催・申込・参加費・対象、問い合わせ先(担当課・電話)。

## 対象と方法
- 対象は、ワード調査(全国)で『イベント』と判定された419ページ(208自治体)。ページを取得し直し(robots順守・1ホスト1リクエスト/秒以下)、ルールだけで取り出す(AIなし、D-050)。HTMLは保存せず、値とワードの前後の短い文(`evidence`)だけ保存する。
- 取り出し: ①題名にグラウンドゴルフがある、または日時・会場の項目があるページは1イベント ②表は、ワードのある行を1イベント(見出し行の列名から日時・会場を取る) ③カレンダー・予定表は、ワードのある行を1イベント(同じ行、無ければ直前の行の日付) ④その他(複数競技の大会・報告)はページ全体を1イベント(グラウンドゴルフは種目として証拠の文に残す)。
- 日付は和暦・西暦・月日だけ(年は題名・本文の『令和8年度』などから補う)に対応。`date_basis` に、日付の出どころ(項目/題名/本文推定)を入れる。

## 限界(実行前に記録)
- 対象は、ワード調査が到達した『イベント』のページだけ。イベント一覧・広報・お知らせのうち、調査が到達しなかったものは含まれない(208自治体より多い可能性)。必要なら、次の段階でイベント専用の探索を足す。
- 主催は、ページに『主催』の記載があるときだけ取る(多くのページは自治体の事業で明記しない)。
- PDF(開催要項)の中身は読まない。
- JavaScriptで描画するカレンダー(一関市など)は、ヘッドレス取得でも取れないことがある。

## 事前基準
| # | 項目 | 基準 |
|---|---|---|
| 1 | ページの取得 | 95%以上 |
| 2 | 取得ルール違反(robots・1秒・ログイン・予約) | 0 |
| 3 | イベントの行が1つ以上取れたページ | 90%以上 |
| 4 | 開催日あり(行) | 60%以上 |
| 5 | 会場あり(行) | 50%以上(グラウンドゴルフ専用の行は70%以上) |
| 6 | 15行の確認(名称・開催日・会場がページと合う) | 9割以上 |

試作(取得済みページ34件で手元確認): 開催日 27/36行(75%)、会場 23/36行(64%)、主催 0/36(記載なしが多い)。
