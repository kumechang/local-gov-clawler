# グラウンドゴルフの施設詳細(名前・住所・電話番号・問い合わせ先)の取り出し: 事前基準

2026-10-18、D-124。ユーザー指示「グラウンドゴルフの詳細ページと、施設の名前、住所、問い合わせ先電話番号がほしい」。結果を見る前に、基準を決める。

## 対象と方法
- 対象: ワード調査の結果(`data/export/grandgolf_places.csv`)の**場所(施設)のページ**1,421件(487自治体)。まず試す3県(愛知・福井・埼玉、約220ページ)。全国には、結果の報告と判断のあとに広げる。
- ページを取得し直す(HTMLは保存していないため)。ルールは調査と同じ(robots.txt、1ホスト1リクエスト/秒、予約・ログインに入らない、JS描画のサイトはヘッドレス)。
- 取り出し(ルールだけ、AIは使わない=D-050): ①見出しの行に『施設名』『住所/所在地』『電話』がある一覧表は、1行を1施設に、②『所在地/住所/電話』の欄(2列の表・定義リスト・『キー:値』の行)は、直前の見出しごとに1施設に、③どちらも無ければ、ページの文から『所在地:…』と電話番号を拾う。施設の欄に電話が無い1施設のページは、『電話』『問い合わせ』のある文の電話を使う。
- **問い合わせ先**: ページの『お問い合わせ(先)』の欄にある担当課と電話番号(施設自体の電話とは別の列)。
- 1つのページに複数の施設がある一覧は、ワードのある施設の行だけにする(`multi_facility`、`keyword_in_item`)。ワードの前後の短い文(`matched_text`)も付ける。
- 出力: `data/extract/grandgolf/<実行>/<都道府県>/<自治体>.json`、CSVは `data/export/by_run/<実行>/grandgolf_places_detail.csv`(全国をまとめたものは後で作る)。列: 都道府県、自治体、施設名、住所、電話、問い合わせ先の課・電話、ページの題名・URL、複数施設のページか、ワードの前後の文。

## 事前基準
1. **取得**: ページの取得に成功した割合が90%以上(404などは、サイトが変わった分として別に数える)。予約・ログイン・禁止パスへのリクエスト0件。
2. **取り出しの割合**(報告。基準は目安): 施設の行のうち、住所が取れた割合 60%以上、施設の電話か問い合わせ先の電話が取れた割合 60%以上。取れなかった型(どんなページか)を報告する。
3. **正確さ**: ユーザーが約15行(型をばらして)を見て、住所と電話番号が合っている割合が90%以上(住所は、市区町村から番地までが合っていれば可。電話は、施設または問い合わせ先として合っていれば可)。外れた型は規則に反映する。
4. 施設名: 約15行のうち、施設の名前として使えるものが90%以上(『公園』『体育施設』のような見出しだけの名前は、外れとする)。
5. 全国(1,421ページ)へは、この結果の報告と判断のあとに広げる。

## 限界(最初から分かっていること)
- ページに住所・電話が書かれていない(地図や画像だけ)、PDFで公開されている、は取れない。
- 1つの文の中に複数の施設が並ぶ場合や、表でない書き方は、取れないか、混ざることがある。
- 『ワードのあるページ』のなかには、施設の紹介でないもの(お知らせ・手続きなど)が混ざる。その場合は施設名・住所が空になる。
