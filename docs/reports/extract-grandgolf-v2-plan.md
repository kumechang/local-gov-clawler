# 施設詳細の取り出し 第2版(全国再クロール)の計画

実行前に決める(結果を見てから変えない)。route=`v2_<都道府県>`(47)。対象は第1版と同じ『場所』ページ(約1,420)。取得は1ホスト1リクエスト/秒以下、robots順守、ログイン・予約に入らない(第1版と同じ)。

## 第1版からの変更(D-129)
- 表の見出し・キャプションにあるワードを、その表の各行の『ワードあり』に含める(出雲市の型)。
- ワードのある文の前後(約80文字)を、項目ごとに `keyword_evidence` として保存する(HTML原本ではなく短い文。D-005の範囲内)。ワードの施設を取り違えたとき、原因を調べられるようにするため。
- 書き出し: 同じページの同じ施設の重複を1行に。同じ自治体にワードのある施設の行(住所つき)があるとき、ページ名そのままの本文由来の行を出さない。

## 事前基準
| # | 項目 | 基準 |
|---|---|---|
| 1 | ページの取得 | 95%以上 |
| 2 | 取得ルール違反(robots・1秒・ログイン・予約) | 0 |

| 6 | 新しい15行の確認(別の抽出、`keyword_evidence` つき)で、施設名・住所・電話が正しい | 9割以上 |

## 見込み(正直に)
- 基準6は届かない可能性が高い。佐久市(ページ名と市の住所を出す)、三種町(複数施設から別の施設を選ぶ)、和歌山市(公園の中の一部の広場)の型は、今回の変更では直らない。`keyword_evidence` はこれらを次に直すための材料にする。
- 基準3・4は第1版とほぼ同じ見込み(住所57%、電話89%)。
