# 施設詳細の取り出し 第3版(全国再クロール)の計画

第2版の新15行の確認(D-132)で、全体の誤りの原因になる不具合が見つかったため。route=`v3_<都道府県>`(47)、対象・取得ルールは第2版と同じ。実行前に決める。

## 第2版の15行の確認(結果)
10/15が妥当(67%)。問い合わせ先の電話が入っていた茅ヶ崎市(#11)を妥当とみなすと 11/15(73%)。ワードのある行(#1〜10)は 8/10、ワードのない行(#11〜15)は 3〜2/5。

## 第3版の変更
1. **ハイフンの別字を読めるようにする**: 数字の間の `‐` `−` `ー` などを `-` にそろえる(城里町の『0296‐88‐3111』が電話番号として読めず、町役場の電話が出ていた。福井市も同じ原因の可能性が高い)。全国の電話の取りこぼしと取り違えに効く。
2. 『○○役場』『○○市役所』『庁舎』は施設の名前として出さない(東員町)。書き出しでも同じ。

## 直さないこと(理由つき)
- 吉賀町: 本文に2か所のグラウンドゴルフ場が並ぶ型(ページ名と別の施設の電話を出す)。本文から施設ごとの区切りを確実に取るルールが作れない。
- 城里町の住所: 本文先頭の〒つきの住所は、ページ下の市役所の住所と区別できない(佐久市の型を悪化させる)。
