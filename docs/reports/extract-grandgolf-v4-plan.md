# 施設詳細の取り出し 第4版(全国再クロール)の計画

第3版の結果(福井市が直らない)と、15行の確認で残った型の調査から。route=`v4_<都道府県>`(47)、対象・取得ルールは第3版と同じ。実行前に決める。

## 調査の方法(D-133)
×だった行のページを、クロールで取得済み(robots 順守・200)のものに限って、手元から1件ずつ取得して原因を確認した(約15件、1秒以上あけた。HTMLは保存していない)。

## 第4版の変更
1. **問い合わせ先**: 『お問い合わせ先』の見出し(h2〜h5・dt)の次の段落から、担当課と電話を取る(福井市の型)。ヘッダ・フッタ・ナビの中の見出しは除く。従来の取り方で取れなかったときだけ使う。
2. **箇条書きの施設**: 『・蔵木グラウンドゴルフ場吉賀町蔵木60-2』のように、施設名の直後に自治体名から始まる所在地が続く箇条書きを施設の行にする。次の【問い合わせ】の電話をその施設の電話にする(吉賀町の型)。
3. **住所・電話の列が無い施設の表**(名称・種別・内容): 施設名だけの行にする。ワードのある行だけ出す(佐久市の型。ページ名と市役所の住所を施設として出していた)。

実ページでの確認: 福井市(問い合わせ先 商工労働部観光文化スポーツ局 スポーツ課 / 0776-20-5355)、吉賀町(蔵木60-2 / 0856-77-0633、大野原969 / 0856-79-2330)、佐久市(やまゆり公園グラウンドゴルフ場)が期待どおり。ほか10ページは第3版と同じ結果(退行なし)。
