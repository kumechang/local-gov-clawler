# 施設詳細の取り出し 第5版(全国再クロール)の計画

第4版の退行(D-134)を直す。route=`v5_<都道府県>`(47)、対象・取得ルールは第4版と同じ。実行前に決める。

## 第5版の変更
1. **施設名だけの表は最後の手段**: 見出し+値・箇条書きで施設が取れないときだけ使う(住所つきの行を隠さない)。
2. 箇条書きの施設名は、施設を表す語で終わるものだけ(『施設の管理運営・スポーツ教室』のような説明を施設にしない。豊中市)。
3. 施設名だけの表の行は、表の見出しのワードを引き継がず、その行自身の文にワードがあるときだけ『ワードあり』にする(安中市)。
4. 施設名だけの行に、ページ全体の電話を付けない。

実ページ(取得済み・200のもの)17件で確認: 奥州市・上田市・洲本市・丹波市・豊中市の行が戻り、吉賀町・佐久市・福井市は第4版のまま。
