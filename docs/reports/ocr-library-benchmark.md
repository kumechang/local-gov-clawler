# OCRライブラリの比較(日本語の自治体PDF)

ユーザー依頼(2026-11-04): 「北海道が終わっていないから、OCRについてもライブラリの性能検証をして」。背景: 北海道の試し(pdf1、pypdf)で、画像だけのPDFが214件(10.7%)読めなかった。

## 比較の方法
- **画像の元**: 日本語の自治体PDF 53件のうち、文字の層があるPDFから、14自治体の20ページ(うち17ページにグラウンドゴルフ)。文字の層の本文を『正解』として使う。
- **条件**: ①きれい(150dpiで画像にしたもの) ②スキャン風(解像度を約6割に下げ、ぼかし・ノイズ・傾き0.6度・JPEG画質35で劣化させたもの)。
- **実際の画像だけのPDF**: 実在の4件(9ページ)。正解は無いので、ワードの検出と文字の量で見る。
- **OCRエンジン**: Tesseract 5.3(日本語。標準=fast、best。ページ分割 psm 3/6)、RapidOCR(ONNX。PP-OCRv4 日本語、PP-OCRv5 軽量)、EasyOCR(日本語、PyTorch)。Surya・PaddleOCR・クラウドOCR(Google/Azure)・NDLOCR は、今回は試していない(重い・外部送信・導入未確認)。
- **指標**: 文字の一致率(文字の集合のF1。読み順の違いに左右されない)、グラウンドゴルフの検出(17ページ中)、1ページの時間(他を止めて測定)。

## 結果
| OCR | 1ページ | きれい: 一致率 / 検出 | スキャン風: 一致率 / 検出 |
|---|---|---|---|
| Tesseract fast(apt標準) psm3 | **0.9秒** | 91.3% / 15 | 75.5% / 13 |
| Tesseract best psm3 | 約2.3秒 | 88.0% / 16 | 74.1% / 14 |
| Tesseract best psm6 | 2.3秒 | 89.5% / **17** | 74.6% / **16** |
| RapidOCR PP-OCRv4 日本語 | 2.9秒 | 94.7% / **17** | 55.2% / 6 |
| RapidOCR PP-OCRv5 軽量 | 約2〜3秒 | **96.7%** / **17** | **83.9%** / 5 |
| EasyOCR 日本語 | 約11〜15秒 | 94.1% / 9/9(11ページ分まで) | 47.3% / 5/9 |

- **きれいな画像**は RapidOCR v5 が最も正確(96.7%)。EasyOCR も良いが約5倍遅い。
- **劣化した画像**では、文字の一致率は RapidOCR v5 が最も高い(83.9%)のに、ワードの**検出は Tesseract が圧倒的**(16/17、v5は5/17)。ワードの文字列が一部崩れ、他の文字が正しくても検出に失敗するため。
- 実在の画像だけのPDF 4件(9ページ)のうち、**葛飾区の『葛飾区グラウンド・ゴルフ協会』のチラシ**に、グラウンドゴルフの記載があった。これを検出できたのは Tesseract fast だけ(RapidOCR は『グラウ』『ゴルフ』は読めたが、つながった形で読めなかった)。画像だけのPDFにも、ワードの記載があることが分かった。
- 1ページの時間は、200dpiのA4で Tesseract fast が約1〜4秒。

## 判断(D-149)
1. **画像だけのPDFの読み取りは、Tesseract(標準=fast)と RapidOCR(PP-OCRv5 軽量)の両方で読み、合わせる**。Tesseract は低画質に強く速い、RapidOCR はきれいな画像で最も正確。どちらかが無くても動く。
2. **ワードの検出は、ゆるいパターン(OCRの1字の誤り)も使う**(`config/keywords/grandgolf.json` の `ocr_patterns`。ド→ト、ゴ→コ、ル→レ)。OCRの文には否定の判定をしない。結果には `ocr: true` と使ったエンジンを残す(確認用)。
3. 先頭6ページ・200dpiまで。GitHub Actions では `tesseract-ocr` と `tesseract-ocr-jpn` を apt で、RapidOCR を pip で入れる。
4. EasyOCR は遅く(約5〜10倍)、スキャン風の画像で弱いので採用しない。Surya・PaddleOCR・クラウドOCR・NDLOCRは、必要になったら別に比べる。
5. 北海道の試しは `pdf3_hokkaido`(pypdfium2 + OCR)で行う(`pdf2` は置き換え)。

## 限界
- 20ページ×2条件の小さな標本。『スキャン風』は人工の劣化で、実際のスキャンとは違う。
- 実在の画像だけのPDFは4件(9ページ)で、正解が無い。
- EasyOCR は全件の完了前に打ち切った(11ページ分まで)。
- 縦書き・手書き・表の読み取りは見ていない。
