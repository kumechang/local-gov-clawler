# PDFを読む試し(愛知・福井・埼玉)の計画

ユーザー依頼(2026-11-04): 「PDFを読むと件数は増えるか」→「愛知・福井・埼玉でやって」。route=`pdf4_aichi`・`pdf4_fukui`・`pdf4_saitama`。

## 目的
北海道(パークゴルフが主流)では、PDFを読んでも新しい自治体は0だった。グラウンドゴルフが多い県でも同じか、を測る。

## 方法
従来のワード調査(`redecide_v12_1` の入口から、1自治体200ページまで、入口から2階層)と同じ範囲で、**PDFも読む**(`--read-pdf`: スポーツ関連のページから出る同じサイトのPDFを1自治体20件・8MB・30ページまで。`pypdfium2`、無ければ `pypdf`)。**画像だけのPDFはOCR**(`--ocr-pdf`: Tesseract + RapidOCR、先頭6ページ、200dpi)。取得ルールは同じ(robots順守、1ホスト1リクエスト/秒以下、予約・ログイン・CAPTCHA・WAFには入らない)。

## 比べる基準(従来の結果)
| 県 | 調べられた自治体 | ワードあり(HTML) |
|---|---|---|
| 愛知県 | 53 | 38 |
| 福井県 | 17 | 7 |
| 埼玉県 | 61 | 37 |
| 合計 | 131 | 82 |

## 事前基準(測るもの)
| # | 項目 | 基準 |
|---|---|---|
| 1 | 取得ルール違反 | 0 |
| 2 | PDFの取得 | 90%以上(404・robots不許可・大きすぎは別に記録) |
| 3 | PDFで**新しく**見つかった自治体(HTMLでは見つからなかったもの) | 数を報告(判断の材料。目安: 5自治体以上なら、全国に広げる価値あり) |
| 4 | PDFで見つかったページ(自治体の内訳、施設・イベント・その他) | 数を報告 |
| 5 | OCRで読んだPDFのうち、グラウンドゴルフが見つかったもの | 数を報告 |
| 6 | 新しく見つかったPDFの精度(10件の確認) | 9割以上が、グラウンドゴルフの施設・大会の記述 |
| 7 | 時間(1自治体あたり、OCRの分) | 報告 |

## 見込み
- 新しい自治体は、少なくとも北海道よりは出る見込み(県のグラウンドゴルフの普及による)。ただし多くはない見込み。
- 「PDFだけにある」自治体が少なければ、全国への広げ方は『既に見つかった自治体の施設・イベントの詳細を増やす』方向になる。
