# PDFを読む調査の設計(グラウンドゴルフ)

ユーザー依頼(2026-11-04): 「PDFを読む設計も進めて」。背景: 北海道のグラウンドゴルフが1%だったのは『見逃し』(D-141)。

## 実証(手元で1件確認)
- 旭川市の『市内パークゴルフ場』の資料PDF(`…/d077979_d/fil/4_2.pdf`、43KB・2ページ)に、『旭川市平成大橋上流右岸広場 … パークゴルフ場1(18ホール) グラウンドゴルフ場1』と書かれている。これは、旭川市のサイトのHTMLページには出ない情報で、今のワード調査(HTMLだけ)では見つからない。
- PDFの文字の取り出しは、`pypdf` でも `pdfminer.six` でも日本語が正しく読めて、ワード(グラウンドゴルフ)が見つかった。
- robots.txt は許可、200、`application/pdf`。

## 今のワード調査の限界
- PDFは取得しない(ページの種類が HTML でなければ読まない)。PDFのリンクの文字にワードがあるときだけ、リンクを記録する(`pdf_link_hits`)。
- リンクの文字にワードが無いPDF(『資料4-2』『施設一覧』『利用案内』など)は、中身にワードがあっても見つからない。北海道では、PDFのリンクの文字にワードがあったのは1自治体だけ(他の都道府県は1,562自治体のうち79)。

## 設計
1. **対象のPDF**: スポーツ関連のページ(入口・一覧・施設・イベントの役割)から出ている、同じサイトのPDFのリンク。リンクの文字・URLの語で優先順位をつける: ワードを含む > 施設・一覧・案内・利用・大会・要項・スポーツ・体育・公園・パークゴルフ・ゴルフ・マップ・パンフ・ガイド > その他。
2. **上限(安全弁)**: 1自治体 20件、1件 8MB・30ページまで。読めない(画像だけ・暗号化)PDFは `no_text` と記録して先へ進む。予約・申込フォームは対象外。
3. **取得ルール**: robots順守、1ホスト1リクエスト/秒以下、UAはリポジトリのURL。PDFは保存しない(読んだ文字のうち、ワードの前後の短い文だけ保存。HTMLと同じ扱い)。
4. **文字の取り出し**: `pypdf`(純Python・軽い)を既定とし、取れなかったときだけ `pdfminer.six`。任意の追加依存 `.[pdf]` として入れる。
5. **記録**: ワード調査の結果に、PDFのページを `kind=pdf`、`via=pdf_text` で足す。URL、題名(ファイル名)、ページ番号、ワードの前後の文、PDFが見つかった元のページ。
6. **分類**: PDFの題名・ファイル名・ワードの前後の文から、『場所(施設の一覧)』『イベント(要項・結果)』『その他(計画・議事録)』に分ける。
7. **次の段階(施設の詳細・イベントの詳細)**: PDFの表(施設名・所在地・種目)を取り出す。表の読み取りは崩れやすいので、まず検出(どの自治体のどのPDFにあるか)を出して、ユーザーが確認してから設計する。

## 進め方(段階)
1. **試し(北海道、`pdf1_hokkaido`)**: 北海道の185自治体で実施。事前基準を先に決める。
2. 結果をユーザーが確認(10件)。精度が出れば、全国へ広げる(ワード調査で見つからなかった自治体が対象)。
3. 検出したPDFから、施設・イベントの詳細を取り出す設計に進む。

## 事前基準(試し)
| # | 項目 | 基準 |
|---|---|---|
| 1 | PDFの取得 | 90%以上(404・暗号化・大きすぎるものは別に記録) |
| 2 | 取得ルール違反 | 0 |
| 3 | 文字を取り出せたPDF | 80%以上(画像だけのPDFは `no_text`) |
| 4 | 北海道でグラウンドゴルフの記述が見つかった自治体 | 現在の2(1%)より増える(目標: 15以上) |
| 5 | 見つかったPDFの精度(10件) | 9割以上が、グラウンドゴルフの施設・大会の記述(計画・議事録の言及だけのものを除く) |

## 見積もり
- 北海道185自治体 × 最大20件 = 最大約3,700件(実際はPDFのリンクが少ない自治体が多く、1,000〜2,000件の見込み)。1ホスト1リクエスト/秒以下で、数時間以内。
- 全国は、試しの結果を見てから見積もる。

## 実装の見積もり
- `survey` に `--read-pdf`: PDFリンクの収集・優先順位・取得(`Fetcher` はPDFを5MBで打ち切るので、8MBに引き上げ、種類がPDFのときだけ)・文字の取り出し・記録。
- テスト: 日本語のPDF(小さな合成PDF)で、取り出しとワード検出を確認。
- ワークフロー: `survey.yml` に `read_pdf` の入力。

## 確認してほしいこと
1. 試しを北海道だけで始めてよいか(おすすめ)。他の都道府県(例: 見逃しが疑われる県)も入れるか。
2. PDFの対象は、スポーツ関連のページから出ているPDFに限る(おすすめ)か、サイト全体のPDFを対象にするか(重く、計画・議事録の言及が増える)。
