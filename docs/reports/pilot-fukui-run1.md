## 分かったこと
1. **確定の誤りのうち、本物のバグは坂井市の1件だけ**。ほかの3件(福井市・敦賀市・若狭町)と小浜市は、**複数の妥当なページがあり、正解データと別のページを選んだ**可能性がある。香芝市と同じで、評価が厳しすぎる可能性。ただし結果を見たあとに許容URLを足すと数字が甘くなるので、**事前基準の判定は「未達成」のまま**とし、許容した場合の数字は別に記録する。
2. **「親の『スポーツ施設』と子の『スポーツ施設一覧』」の扱いは、県によって逆になる**。奈良市の正解は親の「スポーツ施設」(子の「一覧」ではない)だったが、福井市・敦賀市の正解は子の「一覧」。規則では決められない。ユーザーが「どちらも許容」と決めれば、評価は安定する。
3. **奈良県のときと同じく、迷うケースは期待どおり `hub_multiple` になった**(越前市・池田町)。精度優先の方針は機能している。
4. **ナビに入口が無い自治体は拾えない**(永平寺町)。奈良県の河合町・黒滝村と同じ種類の失敗。
