## 原因の分析

### A. 候補が見つからない(20件)
トップページのナビには「スポーツ施設」のような直接のリンクが無く、次のような**大分類・探索用の入口**しか無い自治体が多い。現状のスコアはこれらを0点にしており、先のページを見に行っていない。

- 「施設を探す」(五條市・田原本町・葛城市)、「町の施設」(川西町)、「村の施設」(下北山村)、「趣味・みんなの施設」(十津川村)
- 「教育・文化・スポーツ」(桜井市・三郷町)、「子育て・教育」「教育」(宇陀市・広陵町・御杖村・野迫川村)
- 桜井市・香芝市・河合町は大分類まで辿れていたが、そこで探索が止まっていた(桜井市はスコア6で確定条件の8に届かず)

宇陀市・広陵町・十津川村・下北山村などはリクエスト3件(robots、トップ、サイトマップ試行)で終わっており、トップのリンクから先を一切見ていない。

### B. お知らせ記事が候補に混ざる
「社会体育施設の熱中症対策について」「学校体育施設利用手続きの改正について」「御所スポーツフェスティバル2026」「天理市体育施設指定管理者募集」のような**文章形式のタイトル**が高得点になっている(斑鳩町・安堵町・御所市・天理市)。現状のマイナス語は「大会/イベント/募集…」だけで足りない。

### C. 一覧ページと個別施設ページが競合する
葛城市は「観光・文化・スポーツ」(一覧、12点)と「屋敷山公園内 体育施設情報」(個別、13点)が競合して `hub_multiple` になった。深さ2の個別ページが一覧ページに勝つのは意図と逆。一覧ページの配下にある個別ページは、競合ではなく**一覧ページの根拠**として扱うべき。

### D. 取得・判定の個別の問題
- **山添村(needs_headless)は誤判定**: JS描画ではなく、`<img>` だけのリンク(alt無し)でできた静的ページ。リンクが拾えず「本文もリンクも少ない」と判定された。画像リンクを拾えばよく、ヘッドレスは不要。
- **平群町**: 候補ページの取得で `408 Request Timeout`(http_4xx)。再試行していない。
- **CMS不明が28件**: 実際には共通のURL形式が見えている。`/category/N-N-N-N-N-N-N-N-N-N.html` + `/N.html`(御所市・生駒市・斑鳩町・安堵町・川西町・広陵町・大淀町・下市町の8件)、`/life/N/N/`(香芝市・平群町・三郷町)、`/kanko_bunka_sports/index.html` 型(葛城市・上牧町)、`/oshirase_top/N.html` 型など。シグネチャを足せば大半を分類できる。

## 改善案(未実装。ユーザー確認待ち)

1. 「施設を探す」「町/村の施設」「文化・スポーツ」「教育」「生涯学習」などを**探索用の候補**として追加し、確定にはせず先のページを取得して施設リンクを探す(取得数は6ページ程度に増やす)。
2. 文章形式のタイトル(「〜について」「〜します」「〜のお知らせ」「再開/停止/改正」「令和N年」「第N回」「フェスティバル」「指定管理者」)を減点する。
3. 深さ2の個別ページは、深さ1に確定条件を満たす候補がある間は競合させず、根拠としてだけ記録する。
4. 画像だけのリンクを拾う(alt無しは `href` と画像ファイル名から仮ラベル)。JS描画の判定はリンク数ではなく「本文もリンクも空」に絞る。
5. 408/429/5xx/接続リセットは1回だけ再試行する(Retry-Afterがあれば従う)。
6. CMSのURL形式シグネチャを追加する。

これらは**この39件を見て決めた補正**なので、過学習を避けるため、正解データ10件で効果を測ってから他県に広げる。
