## 原因

1. **D-021(浅い階層を優先)が逆効果**: 生駒市・葛城市・斑鳩町の3件で、複合ラベル(「文化・スポーツ施設」「観光・文化・スポーツ」「生涯学習・スポーツ」)の大分類を、その下にある専用ページより優先して誤採用した。第1回の分析の時点で想定していたリスクが現実になった(D-027)。
2. **採用条件の抜け穴**: 生駒市の「文化・スポーツ施設」は施設名リンクが0件なのに、ラベルに「スポーツ施設」を含むため強い語として採用可能と判定された(`STRONG_TEXT`)。
3. **深さ3のページが候補に出ない**: 橿原市・河合町の正解は、取得した2段目のページの中にあるリンクだが、そのリンクは候補として記録していない。
4. **「複数」が無くなった**: 深さの優先で候補が1つに絞られ、`hub_multiple`(AI判定に回す)が0件になった。迷うケースを確信的に誤採用に変えた形で、方針(迷ったらAI)に反する。

## 次の方針(案)

1. **精度優先にする**: 自動確定は「迷いがない」ときだけ。同点・僅差・複合ラベルが絡むときは `hub_multiple` にして後段(AI/手動)へ回す。誤採用は検出できないが、`hub_multiple` は検出できる。
2. **深さではなく専用性で選ぶ**: 複合ラベル(観光・/文化・/生涯学習・/公民館・/健康・ などと並ぶ)は減点し、専用ラベル(スポーツ施設・体育施設・スポーツ・体育)を優先。施設名リンクが0件の候補は強い語でも採用しない。
3. **2段目のページ内のリンクも深さ3の候補として記録する**(取得はしない)。
4. 個別施設ページ(「○○ 施設情報」)は一覧の根拠にとどめ、上位候補から外す。
5. **検証用の正解データを追加する**(奈良県の残りの自治体)。今の10件は難しいものを選んでいるので「開発用」。ランダムに選んだ検証用が必要。
