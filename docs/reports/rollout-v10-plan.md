# v10の確認計画と事前基準(結果を見る前に記録)

関連: D-075〜D-081 / 前提: `docs/reports/rollout-v9-result.md`

## 変更点(v9→v10)
1. **施設の数え方**(D-079): リンクに加えて、リスト/表の項目(li・dt・dd・td・th)の文字も数える。強いお知らせ語を含むものは数えない。弱いお知らせ語を含むものは、きれいな施設名が2件以上あるか合計3件以上のときに数える。同じ施設への言及は1件。運動施設語の辞書を拡張
2. **規則R**(D-080): `sports_other` の確定/1位の、1つ上の階層の題名が専用ラベルで施設2件以上なら、親を採る

診断(`link_samples`・`breadcrumb`・`parent_check`・`body_terms`)はv9のまま。

## 対象と比較
奈良県39・福井県17・愛知県54・大阪府43・島根県19(区を除く)= 計172自治体。比較は v9 の route(`actions_direct_v9_*`)との差分。
