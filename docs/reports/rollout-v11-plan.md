## 変更点(v10→v11、D-083)
1. 本文の項目・弱いお知らせ語・同じ施設は1件、の数え方は、専用ラベル(`sports_pure`)と強い語を含む複合ラベルのページだけ。それ以外は v9 のリンクだけ
2. 確定の順序: 専用ラベル → 強いラベル → 浅い → スコア
3. 強いお知らせ語に 日付・更新・寄附・寄付 を追加。NOT_LISTING に 予約・専門学校・大学・高等学校 を追加
4. 規則Rは v10 のまま
