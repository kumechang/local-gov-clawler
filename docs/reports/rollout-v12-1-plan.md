# v12.1 同点のタイブレーク: 事前基準(結果を見る前に決める)

2026-10-16、D-103の続き。ユーザー指示「推奨で進めて」(規則案を実装し、事前基準を決めて再実行)。

## 変更(hub.py)
- **T4** 『…について』の文章のラベルは、施設名が並ぶページより後(読谷村)
- **T1** 同点の中で、名前に『一覧』がある候補だけを残す(出雲市)
- **T2** 同点の中で、専用ラベル(sports_pure)の親ページが他の全候補の親なら、親(入口)を採る(一宮市、刈谷市)
- **T3** 同点(hub_multiple)で、上位の候補(個別の施設ページ)の1つ上のページが汎用ラベル(公共施設利用案内 など)で施設リンクが3件以上なら、それを採る(太良町)。予約・申込のタイトルは除く
- 絞れなければ従来どおり hub_multiple。**同点でない自治体の判定は変えない**

## 実行方法
判定ルールだけの変更なので、自治体のサイトには接続せず、保存済みの結果(上位5候補と親ページの確認結果)から判定をやり直す
(`localgov-crawler redecide`、新しいroute `redecide_v12_1`)。取得は伴わないので、1ホスト1リクエスト/秒の制約には触れない。
限界: 新しい選択の『親ページ』は、元の実行で確認した親のときだけ使える(別の候補が新しく選ばれても、その親は取得していない)。

## 事前基準(結果を見る前に決める)
対象: v12の全国の結果(`actions_direct_v12_*`、政令市の区を除く1,747件)。

1. **退行ゼロ**: v12で `hub_selected` だった自治体の確定URLが、1件も変わらない(変わったら原因を調べ、規則を直す)
2. **正解データ21件**: 正解として確定した件数が、v12より減らない。誤った確定(正解にも許容URLにも入らない)が増えない
3. **代表8件**: 規則の対象である出雲市・一宮市・太良町・読谷村が、正解(許容を含む)で確定する
4. **効果**: hub_multiple(v12で169件)がどれだけ減るか、新しく確定した自治体の一覧を出す
5. **新しく確定したものの精度**: 新しく確定した自治体から、種類をばらして約10件を選んでユーザーが判断する。誤りが2割を超えたら、その規則を取り下げる(確定でなく同点のままに戻す)

判定は結果を見たあとで、この基準どおりに行い、基準を変えた場合は理由を記録する。
