# v8の確認計画と事前基準(結果を見る前に記録)

関連: D-067〜D-069 / 前提: `docs/reports/rollout-stage1-result.md`

## 変更点(v7→v8)
1. 整備/建替/改修/耐震/開放/システムを含む専用ラベルは自動確定しない(候補には残す)
2. 施設名リンクに数えない語の追加(開場/設置/空調/講習/講座/教室/皆さん/皆様/お願い/ください/ご利用)
3. 診断 `body_terms`(リンクでない本文中の施設語の出現数)。判定には使わない

## 対象と比較
奈良県39・福井県17・愛知県54・大阪府43・島根県19(区を除く)= 計172自治体。比較はそれぞれの v7 の route との差分(`actions_direct_v7` / `_v7_fukui` / `_v7_aichi` / `_v7_osaka` / `_v7_shimane`)。正解データは作らない。

## 事前基準
| # | 項目 | 基準 |
|---|---|---|
| 1 | 意図した変更 | 段階1の疑わしい5件(岡崎・常滑・あま・堺・東大阪)の確定が外れる(別ページに変わった場合は、そのページを個別に確認する)。5件中4件以上 |
| 2 | 意図しない確定の変化 | 上記5件と河内長野市を除く確定の変化は、172件中2件以下。変化した件は個別に確認して、良い・悪い・同等を報告する |
| 3 | 奈良県・福井県の確定 | 開発用・検証用の正解データに対する確定の精度が、v7と同じ(100%、事後の許容後)。到達の低下は1件以内 |
| 4 | 取得面 | v7と同じ(失敗率0%付近、平均リクエスト数は±2以内) |
| 5 | 診断 | `body_terms` が取得済み候補に記録されている |

報告するだけ(基準なし): 施設名リンク0〜1件で確定できなかった9件(瀬戸・新城・尾張旭・豊明・長久手・松原・門真・大田・吉賀)の `body_terms` の合計(施設語が多数あれば「文字で並ぶ一覧ページ」の仮説を支持)。判定への利用は、結果を見てからユーザーに諮る。

## 判断
1〜4を満たせば、残り44都道府県(区を除く約1,630件)を数回に分けて実行する案を提示する。満たさなければ原因を報告し、広げない。
