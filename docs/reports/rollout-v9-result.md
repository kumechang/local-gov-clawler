## ユーザーの3つの判断基準(D-075, D-076)との対応
1. リスト形式になっている → 現在は「施設名のaタグリンク数」。リストの構造(li/tr/dt/dd)を数えていない
2. 運動を連想する施設がいくつか並ぶ → 現在は固定の語。「運動広場」「スポーツパーク」「スケボーパーク」「アリーナ」等が漏れる
3. **イベントなど他の情報があっても、運動施設のリストがあれば一覧と判断する** → 現在は、お知らせ・講座・「ご利用」「について」などを含むリンクを施設名リンクから除外している(D-058/D-072)。これは安堵町(同じ施設の工事のお知らせを何件も数えた)への対処だったが、人間の基準とは逆向き。重複を施設ごとに数える(同じ施設への言及は1件)方法に置き換えると、安堵町型は防げて、松原市のような「お知らせ風に書かれた施設名」を数えられる

## 提案: v10
1. **施設を重複なしで数える**: 施設名の語を含むリンクを、お知らせ風の書き方でも数える。ただし、施設の名前(語までの部分、先頭の【…】を除く)が同じものは1件にする。件数の基準は、お知らせ風のリンクを含むときは3件以上にする(安堵町型を防ぐ)
2. **リストの構造を数える**: リンクでなくても、li/tr/dt/dd の項目のうち運動施設の語を含むものを数える(尾張旭市・長久手市・大田市・吉賀町型)
3. **運動を連想する語の辞書を広げる**: 運動広場・スポーツパーク・アリーナ・スケボー(パーク)・海洋センター・ゲートボール・フットサル・柔道/剣道/弓道 など
4. **「1つ上へ上がる」規則R**(上記): `sports_other` の確定または1位が、題名が専用ラベルの親ページ(2件以上)の子なら、親を採る
- 検証: 6つの正解データ+段階1の確認用(常滑・東大阪)で、精度が下がらないこと。段階1・2の差分で、新たに確定するページと、確定が変わるページを個別に確認する。正解データが無いので、確定が増える分(取りこぼし9件、春日井・刈谷など)は、ユーザーに候補ページを確認してもらう
