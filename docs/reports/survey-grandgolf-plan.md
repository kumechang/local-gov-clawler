# ワード調査(グラウンドゴルフ)パイロット: 事前基準

2026-10-16、D-106・D-107。パイロットは愛知県(名古屋市の区を除く)と福井県。結果を見る前に、この基準を決める。

## 目的と対象
- 探すもの: 「グラウンドゴルフ」(表記ゆれ: グラウンド・ゴルフ、グランドゴルフ、半角、空白入り)が書かれている、**スポーツ施設(の一覧・詳細)のページ**、**自治体(のスポーツのページ)**、**自治体のイベントのページ**。
- 次回は別のワード: `config/keywords/<名前>.json` を足すだけでよい(コードは変えない)。

## 方法(`localgov-crawler survey`)
- 入口: 保存済みのハブ判定(`redecide_v12_1`)の確定ページと上位候補(同点も全部)、トップのナビの「スポーツ…」「大会・イベント…」の入口。最大12件。
- そこから同じサイト内を**2階層**までたどる(施設・種目・場所の語を含むリンク、イベント/大会/教室の語を含むリンク、ワードそのものを含むリンク)。
- 取得するページ数の上限は1自治体200(サイト全体をたどらないための範囲の限定。時間のためではない)。
- 本文のうち、ナビ・ヘッダー・フッター・サイドバーは外す(全ページに出るワードを拾わない)。題名・本文・本文内のリンク文言で一致を見る。
- 保存: ワードの有無、ページURL、役割(listing/facility/event/sports_nav)、前後30文字の短い文(最大3)。本文は保存しない。PDFは取得せず、リンク文言にワードがあるものだけ記録。
- ルール: robots.txtのDisallowは取得しない、1ホスト1リクエスト/秒以下、予約システム・ログインには入らない、CAPTCHA/WAFは突破しない。
- 出力: `data/survey/grandgolf/<route>/<都道府県>/<自治体>.json`、集計 `data/summary/survey_grandgolf_<route>.{csv,md}`。

## 事前基準
1. **運用**: 取得失敗(`fetch_failed`)が、入口のある自治体の10%以下。予約・ログインのURLや robots 禁止のパスへのリクエストが0件。
2. **範囲**: 取得ページ数の上限(200)に達した自治体が、調査できた自治体の20%以下。超えたら、たどり方が広すぎないかを調べる。
3. **精度**: ワードが見つかった自治体から約10件(役割別にばらして)を選び、ユーザーが判断する。『そのページにワードがある、かつ、スポーツ施設・自治体・イベントのどれかの話』が9割以上。外れた型は規則(ナビの除外・役割)を直す。
4. **見逃し**: ユーザーが、愛知県・福井県で『グラウンドゴルフが載っているはず』の自治体を数件、『載っていないはず』を数件教えてくれたら、それとの一致を見る(任意。無ければ、ワードのあった割合と、入口が無い(`no_seed`)割合を報告するだけ)。
5. 全国には広げない。パイロットの結果を報告し、判断をもらってから広げる。

## 限界(最初から分かっていること)
- ハブ判定の入口が無い、またはJS描画のサイト(`needs_headless`)は調べられない(`no_seed`として数える)。
- PDF(広報・大会要項など)の中身は読まない。PDFのリンク文言にワードがあるものだけ記録する。
- 協会・公民館など自治体サイト以外のイベントは調べない。
