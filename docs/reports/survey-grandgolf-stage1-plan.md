## 事前基準
1. **運用**: 取得失敗は、入口のある自治体の10%以下。予約・ログイン・禁止パスへのリクエスト0件。上限200に達した自治体は20%以下。
2. **本文の取り出し**: 本文が200文字未満のページの割合が30%以下。超える県があれば、その県のサイトの型(JS描画など)を調べる。
3. **精度**: ワードが見つかった自治体から約10件(県と種類をばらして)をユーザーが判断し、9割以上が妥当。外れた型は規則に反映する。
4. **否定の文**: 外した件数(`negated`)を報告し、外したものの文を数件、ユーザーに見てもらう(誤って外していないか)。
5. **入口なし**: `no_seed` と `needs_headless` の件数を県別に報告する(調べられなかった自治体)。
6. 報告: 県別の『ワードあり』の割合、ワードのあったページの種類(facility / event / organization / other)。
7. 全国へは広げない。この結果の報告と判断のあとに、次の段階(残りの県)を決める。
